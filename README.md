## Разработка и публикация

Согласованные изменения сохраняются в локальной папке проекта и в этом репозитории. Главная страница — index.html; каждый выпуск дополнительно хранится в obmerka-vNNN.html. При выпуске обновляется имя кэша в sw.js. После push проверяется удалённый коммит и версия на GitHub Pages.

Сборка v195: Python 3, `python3 tools/build_v195.py` (основа obmerka-v194.html). Проверка: `node tools/make_test.js "Дизайн-проект кв. 109 — Шаумяна 14 (v195).html"`, затем `node tools/t195.js` с установленным Playwright и его Chromium. Снимки тестов сохраняются в drawings/; перед проверкой создайте эту папку.

Публикация приложения и синхронизация пользовательских планов — разные операции. Данные планов сохраняются локально в браузере, в скачанных файлах и, при отдельной настройке, в выбранном репозитории данных GitHub.

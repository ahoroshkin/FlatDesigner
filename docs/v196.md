# Обмерка v196

1. Откройте «Отображение» (значок слоёв справа от плана).
2. Снимите галочку «Показывать подъезд». В плане и списке помещений останется квартира. При необходимости нажмите «Вписать», чтобы разместить квартиру по центру экрана.
3. Для работы с фреонопроводами до шахты верните галочку. Данные трасс, их полные длины и состав чертежей не зависят от этой настройки.

Положение переключателя сохраняется в браузере отдельно для каждого проекта. Он появляется в проектах с общими помещениями этажа, названными как в плане квартиры № 109. Та же галочка действует на 2D-план и 3D. При выключенном подъезде 3D показывает квартиру с входной дверью.

На телефоне в режиме «Объект» выберите стену для замера. Введите длину или измените значение кнопками ±10 мм, затем выберите, какой конец стены двигать.

Для открытия свежей версии приложения токен не нужен. Токен относится к синхронизации ваших рабочих планов с репозиторием данных.

Чтобы редактировать свет сразу по квартире, откройте «Инженерия → Свет» или «Отделка → Потолки» и выберите «Все помещения» в верхнем левом списке. Нажмите на светильник для открытия карточки или перетащите его на плане. Если светильники собраны в раскладку, перетаскивание перемещает раскладку целиком. Выбор конкретной комнаты в списке возвращает её потолок.

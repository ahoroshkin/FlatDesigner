# Обмерка v195

23.10.2026. Основа — v194. Существующие планы, стены, двери и трассы не заменяются.

## Плинтус
1. В режиме «Офис» откройте «Отделка → Пол · плинтус».
2. Выберите помещение, включите установку и категорию: ПВХ, МДФ, Дюропласт / полимер, Скрытый монтаж.
3. Выберите магазин и модель. Стартовый каталог содержит четыре карточки Петровича. В категории скрытого монтажа и для Лемана ПРО параметры можно внести вручную: название, артикул, ссылка, размеры и цвет.
4. Размеры и карточка сохраняются в проекте. Кнопка «Сохранить в мой каталог» добавляет модель в каталог именно этого проекта. Интернет для последующей работы не требуется. Цена и наличие автоматически не обновляются.
5. В «Участках установки» включите нужные стены. Начало и конец задаются от первого угла стены; пустой конец означает всю длину. Двери, арки, лифтовые двери и условные границы исключаются автоматически. Окна выше плинтуса его не разрывают.
6. Для скрытой системы задайте монтажный профиль и вставку. При необходимости включите LED; задайте ленту, Вт/м, напряжение, температуру, направление света, рассеиватель, блок питания и его место. Подсветку можно отключить на отдельных стенах.
7. Группа света связывает подсветку с выключателем через существующий раздел «Электрика». Ведомость показывает ленту и расчётную нагрузку. Блок питания выбирается вручную; 20% — используемый в программе запас для предварительного подбора, не паспортное требование производителя.
8. Плинтус виден на плане, полу, развёртке и в 3D. Накладной профиль показан по габаритам; скрытый — лицевой плоскостью. Сложное сечение и монтажная ниша не моделируются. Направление света и температура сохраняются как спецификация; свет в сцене условный, без светотехнического расчёта.
9. «Ведомость» показывает длину после вычета проёмов, количество планок, остаток/запас. Раскрой предварительный: стыки длинных стен и пропил 3 мм, без оптимизации угловых запилов. Комплектующие задаются вручную по системе производителя.

## На объекте с телефона
1. «Аа → Объект» (на телефоне включается автоматически).
2. Внизу: Замеры, Проёмы, Фото, Ещё. Замеры и проёмы работают на исходном плане.
3. «Вся комната» приближает выбранное помещение. Изменения конструкции сохраняют прежние ограничения v194.
4. Карточки снизу ограничены по высоте и не перекрывают нижнюю навигацию. «Кратко / подробно» раскрывает пояснения.
5. Сохранить файл, открыть проекты/синхронизацию, записать заметку, открыть диагонали, вернуться в Офис — через «Ещё».

## Слои и сохранение
В «Слоях» три независимых столбца: Вид, Правка, Печать. Скрытие на экране не исключает слой из общего PDF-отчёта. Конструктивные ограничения действуют дополнительно к блокировке слоя.

«На устройстве» — локальное хранилище рабочего плана. «Файл» — отдельная скачанная HTML-копия. Индикатор GitHub относится к синхронизации рабочих планов, которая настраивается в «Проектах». Обновление приложения на GitHub Pages через Git — отдельная операция и не означает автоматическую отправку рабочего плана из телефона.

# v213 — створки, зеркала и грани стен

- Материал каждой створки раздвижной перегородки выбирается отдельно; отображается на плане, развёртке и в 3D. Общее заполнение можно применить ко всем створкам.
- Зеркала отражают сцену. Отражения ограничены по разрешению и обновлениям; ресурсы освобождаются при пересборке. Основа THREE.Reflector r128, MIT.
- Кнопка зеркала снизу по центру, 45 мм от нижнего края.
- Окрашивание стены учитывает выбранную грань: внутренняя сторона, обратная, торец и откос имеют независимую отделку. Для внутренней стороны сохранена совместимость fin3w; новые поверхности хранятся в fin3faces213. Сброс действует на выбранную поверхность.
- Встроен снимок zgd23g99 updated1794912004311. Расстановка и зелёная отделка гостиной сохранены. v212 оставлена отдельно.

Проверены UI материалов, сохранение настроек створок, фактическое отражение объектов, движение зеркальной створки, кэш, ограничение узкого экрана, окрашивание и сброс граней после пересборки. Реальный телефон не проверялся.

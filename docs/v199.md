# v199 — сохранение проекта

Дискета в верхней панели открывает три действия: скачать JSON, скачать HTML с проектом, сохранить в GitHub. JSON стоит первым. В режиме «Объект» дискету больше не скрываем. Ctrl/Cmd+S и кнопка напоминания о сохранении открывают то же меню.

JSON использует прежний формат экспорта без фотографий. Скачивание JSON не обновляет статус HTML-копии. HTML сохраняется прежним способом. GitHub использует настроенную синхронизацию с приватным репозиторием данных; результат операции показывается отдельно. При отсутствии подключения открывается настройка. Конфликт версий и выполняющаяся синхронизация не выдаются за успешное сохранение.

Проверены реальные скачивания JSON/HTML на копии проекта, сохранность геометрии и трасс, независимость статуса HTML, клавиатура, настройки GitHub и имитации успеха/ошибки/занятости, экран 390×844. Полная регрессия на шести проектах прошла. Реальное мобильное устройство требует пользовательской проверки.

Сборка: `python3 tools/build_v199.py`. Основа — `obmerka-v198.html`. Проверка: `node tools/make_test.js obmerka-v199.html`, затем `node tools/t199_save_menu.js <проект.json>`.

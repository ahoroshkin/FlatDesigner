# Обмерка v197

- В «Инженерия → Свет» или «Отделка → Потолки» выберите «Все помещения», затем нажмите на ряд или сетку светильников. Ручка «+» перемещает раскладку, «⟳» поворачивает, «↔» и «↕» меняют шаг. Ручки доступны и на потолке отдельной комнаты.
- «В браузере» показывает состояние автосохранения на этом устройстве. «HTML-копия» показывает состояние отдельного файла. Если правки внесены после начала выгрузки, их нужно записать в новую копию.
- Если браузер скачивает файл через «Загрузки», приложение может подтвердить только запуск скачивания. При прямой записи выбранного файла появляется «HTML-копия: сохранена ✓».
